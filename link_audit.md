# Verificación de enlaces compartidos

| Recurso | Estado de acceso | Decisión de integración |
|---|---|---|
| Aula del Módulo 0 | Redirige a la autenticación de UMVirtual | Se mostrará como enlace institucional que requiere credenciales; las capturas aportarán la evidencia visual. |
| Grupo de Telegram del Módulo 2 | Accesible mediante página pública de invitación | Se enlazará como ejemplo de expansión comunicacional del aula. |
| Instagram de la Especialización | Redirige a autenticación de Instagram en el navegador de verificación | Se conservará como enlace externo; conviene usar capturas propias para exhibir contenidos durante la exposición. |

La navegación del aula no se reproducirá en vivo como requisito de la exposición. Se mantendrá una demostración visual a partir de capturas y se abrirá el enlace solamente si el equipo cuenta con sesión iniciada.

La vista pública de Telegram permite mostrar una tarjeta de acceso del Módulo 02 con información general y sin mensajes individuales. Se preparó una captura de esa vista para una ventana emergente. Instagram continúa redirigiendo a inicio de sesión; para incorporar una ventana emergente con evidencia real se requiere una captura proporcionada por el equipo, preferentemente de perfil o de una publicación sin datos personales sensibles.
